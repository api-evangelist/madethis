# MadeThis

> MadeThis (madethis.com) is a Y Combinator Fall 2025 startup in San Francisco, founded in 2025 by Jacob Wright, Cambree Bernkopf and Santiago Gomez Paz, marketed as "Your AI Co-Founder" and "the autonomous business platform". A founder describes a business idea and a team of AI employees builds and runs it — website and app development, Stripe-based checkout and billing, ad campaign creation and optimization, 24/7 AI customer support, email automation and cold outbound, market and competitor research, and code generation and deployment. An Enterprise line builds a "company brain" digital twin and trains AI employees on a customer's top performers. MadeThis is an end-user SaaS product: it publishes no public API, no developer portal, no SDK, no CLI and no API documentation.

## Identity and machine-readable surface
MadeThis publishes no API specification. The only machine-readable documents any MadeThis host serves are the identity-discovery documents on `clerk.madethis.com`, a MadeThis-controlled subdomain running a vendor (Clerk) identity instance. They describe end-user sign-in to the MadeThis product, not a callable MadeThis API.
- [OpenID Connect discovery](https://clerk.madethis.com/.well-known/openid-configuration) — issuer `https://clerk.madethis.com`, authorization code flow, PKCE S256, RS256 ID tokens.
- [OAuth 2.0 authorization server metadata (RFC 8414)](https://clerk.madethis.com/.well-known/oauth-authorization-server) — scopes `openid`, `profile`, `email`, `public_metadata`, `private_metadata`, `offline_access`, `user:org:read`.
- [JWKS](https://clerk.madethis.com/.well-known/jwks.json)

## Notes for agents
- There is no MadeThis API, OpenAPI, GraphQL schema, AsyncAPI, webhook catalog, SDK, CLI, Postman collection, agent card or MCP server. Every spec path probed on `madethis.com` and on the product backend `api.madethis.com` returned 404 on 2026-08-13; `api.madethis.com` is a Convex HTTP-action host that answers "No matching routes found" on every path.
- MadeThis *consumes* MCP rather than publishing it: its Enterprise page states that customer systems beyond the named native integrations "connect through MCP & ACP". Do not treat that as a MadeThis MCP endpoint.
- `github.com/madethis` is a DIFFERENT company (Made This, Odense, Denmark, madethis.dk). MadeThis (YC F25) has no public GitHub organization.
- `robots.txt` allows `/` and disallows `/dashboard/`, `/admin/`, `/api/`, `/billing/`.
- Backed by Y Combinator (Fall 2025).
